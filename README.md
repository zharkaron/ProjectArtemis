# ProjectArtemis

ProjectArtemis is a self-hosted VPN infrastructure running on a DigitalOcean droplet.  
It is designed for secure remote access to personal services, home lab environments, and private networking.

---

## 🚀 Current Features

- WireGuard-based VPN server
- Cloud-hosted on DigitalOcean
- Secure SSH-based deployment pipeline (GitHub Actions)
- Automated updates from GitHub repository
- Lightweight and optimized for low-resource VPS instances

---

## 🧠 Tech Stack

- VPN: WireGuard
- Hosting: DigitalOcean Droplet
- CI/CD: GitHub Actions
- OS: Linux (Ubuntu/Fedora)
- Deployment: SSH + Git-based updates
